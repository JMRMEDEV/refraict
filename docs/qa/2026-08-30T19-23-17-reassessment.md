## Fixed and verified

### C1 / C2 / G1 — Component collapse (critical) — FIXED, test-proven
New `internal/cli/repair.go` adds `repairComponent()`, wired into the analyze crop loop. It:
- Synthesizes IDs (`cropID + "-" + idx`) when the VLM returns `""`.
- Recovers empty boxes via OCR-token text match (fallback 1), then the enclosing crop box (fallback 2).
- Clamps boxes to crop ∩ image bounds; drops a component only when no box is recoverable.

Verified: six `TestRepairComponent*` unit tests plus `TestBrokenVLMOutputDoesNotCollapse` (integration-style regression) all pass. The integration test replays the exact e2e failure mode (empty IDs + zero boxes + text) through repair → reconcile and asserts non-null output with recovered OCR boxes. This also closes **G3** (regression test).

### G2 — Box-failure quality signals — FIXED
`page.json` `escalation` now emits `components_box_failed`, `components_box_repairs`, `components_dropped`.

### C3 — Duplicate stage timings — FIXED
Replaced `msSince(start)` duplication with real per-stage deltas via `stageTimes` / `lastStageAt` and `resetStageTimes()`. `msSince` removed.

### B1 — Cache path split — FIXED
New `resolveCacheDir()` in `cache_cmd.go` loads config and reuses `resolveCacheDB`, so `cache status`/`clear` target the same directory `analyze` writes to. The hardcoded `./.refraict-cache` is gone.

### B2 — Cache naming — FIXED
Config key renamed `database` → `dir`, with a custom `CacheConfig.UnmarshalJSON` preserving backward compatibility for the legacy `database` key. Docs corrected to state "No SQLite is used." Verified by `TestCacheDirBackwardCompat`.

### B3 — `Role` serialization — FIXED
`Component.Role` is now `*ConstString` (pointer), so `omitempty` works and empty roles won't serialize.

### B4 — `reconstruct` error variable — FIXED
Now `if err := json.Unmarshal(...); err != nil`, wrapping the real error.

### B5 — Benchmark stub — FIXED
`cropPlanOnly` now calls the real `crop.PlanFixed(W, H, side, overlap)` instead of returning a hardcoded single region.
